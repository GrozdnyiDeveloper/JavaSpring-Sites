# Учебные приложения на JavaSpring
В данном репозитории представлены учебные веб приложения написанные на языке Java с использованием фреймворка Spring. 

**Архив имеет следующее содержимое:**
- demo - Проект, содержащий простое веб-приложение (JavaSpring) для развёртывания сайта с простыми калькулятором и конвертором валют
- DAOProject - Проект, содержащий простое веб-приложение (JavaSpring) для развёртывания сайта с информационной системой на основе паттерна DAO (Data Access Object)
- DBProject - Проект, содержащий простое веб-приложение (JavaSpring) для развёртывания сайта с системой управления базой данных с реализацией полного CRUD для 6 сущностей и поиск по ним 
- LinkProject - Проект, содержащий простое веб-приложение (JavaSpring) для развёртывания сайта с системой управления базой данных магазина с реализацией полного CRUD, поиска и управления связями между сущностями
- AuthProject - Проект, содержащий простое веб-приложение (JavaSpring) для развёртывания сайта с системой управления базой данных магазина (из проекта LinkProject) с возможностью регистрации и авторизации пользователя
- AccessProject - Проект, содержащий простое веб-приложение (JavaSpring) для развёртывания сайта с системой управления базой данных магазина (из проекта AuthProject) с разграничением доступа и распределением функционала по ролям
